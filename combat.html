天赋与模组

TALENTS / MODULES
TALENT 01

深海掠食者

精英二：编入队伍时，所有【深海猎人】干员的攻击力 +14%。她不仅是输出，也是深海体系的核心增益之一。

TALENT 02

迅捷出击

精英二：自身再部署时间 -10 秒。配合 S2 的空降单切，让她能更频繁地回到战场。

DRE-X MODULE / 往日残梦

为单切而生

攻击被阻挡的敌人时，攻击力提升至 115%；迅捷出击进一步缩短再部署时间（2 级 -20s / 3 级 -30s）。

  • 适合空降单切与高频再部署
  • 更强调“落地、解决、撤退”的节奏
  • 对阻挡目标有额外伤害收益
DRE-Y MODULE / 潮湿的剑袋

为深海队而生

深海掠食者强化为全队攻击 +18% / +22%，并额外提供生命 +10% / +20%；特性追加一次免死回复，但会降低生命上限。

  • 适合深海猎人体系与站场
  • 把个人强度转化为团队增益
  • 免死效果每场只触发一次，注意时机

定位与用法

ROLE / TACTICS
01 / DROP

空降单切

把 S2 斯卡蒂直接放在精英敌人脸上，利用落地后的高攻击窗口解决目标。打完就撤，等下一次再部署。

02 / HOLD

高压站场

S3 提供极高的攻击、防御与生命加成，适合阻挡高攻目标或拖住波次。需要治疗与减伤支持。

03 / ABYSS

深海核心

Y 模组让她的天赋覆盖全队。与歌蕾蒂娅、幽灵鲨等深海猎人同队时，她既是输出，也是增益节点。
